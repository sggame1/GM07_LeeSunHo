간단한 TextRPG를 만든 프로젝트입니다.
객체지향을 구조를 기반으로 전투,스킬,아이템 시스템 등을 구현했습니다.

전투 흐름 관리

등 객체지향 구조를 고려하며 제작했습니다.

## 주요 기능
턴제 전투 시스템

● 플레이어와 몬스터가 턴 방식으로 전투

● 몬스터 처치 시 다음 스테이지 진행

● 플레이어 체력이 0이하가 되면 게임 종료
